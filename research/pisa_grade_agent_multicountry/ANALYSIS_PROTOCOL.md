# 多国分析开发协议

本版本先完成可复现的数据准备、调整集明示与学校分组交叉拟合测试，暂不将结果写入投稿正文或替换智能体证据。

研究顺序：数学成绩影响因素分析 → 将分析发现用于诊断智能体 → 与普通大模型比较。MRLE不属于本研究的结果变量，不复制另一篇论文的19个教育系统。

## 样本与变量

开发样本采用原研究12个因素。FEELSAFE、REPEAT不进入共同完整条件。按各系统原始样本至少1000人、至少30所学校、各因素覆盖率至少70%、共同完整样本至少500人且保留率至少50%进行开发纳入。此为作者分析选择，并非OECD标准；不得依据模型系数方向、显著性或智能体表现调整阈值。阈值敏感性与样本流失分析尚待完成。所有系统正式纳入仍需核查抽样质量标记与测量可比性。

共同样本要求12因素、年龄、性别、家庭语言、父母职业和教育信息完整。移民背景在日本等系统全部缺失，不作为主样本通用完整条件；需在可用系统中作为扩展调整敏感性变量。此调整依据覆盖审计，不依据效应方向或显著性，属于开发阶段方案修订，不声称预注册。保留符合系统纳入要求的更广样本，以支持后续逐因素样本及缺失处理敏感性分析。完整案例分析不能消除选择偏倚。

## 调整集与因果识别

先生成单目标因素背景调整与多因素相互调整的两套开发模型。ESCS目标模型不控制ESCS组成项；HOMEPOS模型以父母职业教育替代ESCS，避免合成指标与组成部分的机械控制。其他因素以ESCS为背景条件，不重复加入其组成项。学校当期变量、年级、其他心理与课堂因素不无条件视为前置混杂；相互调整是替代条件关联规格，不等于已识别直接效应。

研究保留因果推断目标，但横截面数据的时间先后、未测混杂、反向因果和处理定义未由代码解决。开发估计标记为调整关联，不能自动命名为干预效应，也不据此直接生成个体因果判断。

## 推断与测试

五折交叉拟合按系统分层、按全局学校键分组。预处理仅在训练折拟合。最终学生权重同时进入辅助模型与残差估计。开发主权重为系统等权，原始权重作敏感性。学校聚类方差不等于完整PISA设计方差。正式推断必须分别分析全部十个合理值；重复权重分析须区分固定辅助模型的末端分数重加权与全流程重拟合。

真实数据小样本测试仅验证工程运行，不用于教育结论。模型、SHAP、留系统验证、完整DML、权重与调整集敏感性、多重检验、正式智能体导出和图表属于后续步骤，未运行不得标记完成。
